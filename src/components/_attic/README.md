# Attic

These files are **unreferenced legacy UI**, kept only for salvage.

Nothing in the app imports from this folder, and nothing may start to. They were
moved here during Phase 0 of `ANTIGRAVITY_BUILD_PLAN.md` because they were still
being compiled into the shipped bundle despite having no importers.

If you need something from here, copy the specific code you want into a real
component — do not add an import path into `_attic/`.

Deleting these permanently is a later, separate decision.
